# Tauri + React + TypeScript + Vite + shadcn/ui

A cross-platform desktop app template built with [Tauri 2](https://v2.tauri.app/),
React 19, TypeScript, Vite, Tailwind CSS v4, and shadcn/ui.

The template ships with a fully themed, frameless window shell: a custom
cross-platform titlebar with native window controls, Windows 11 snap-layout
support and rounded corners, a persisted theme, and window position/size
restoration — so you can start building features instead of window plumbing.

## Stack

| Layer     | Tech                                                                 |
| --------- | -------------------------------------------------------------------- |
| Frontend  | React 19, TypeScript, Vite, Tailwind CSS v4, shadcn/ui, react-aria-components, Phosphor Icons, Inter font |
| Backend   | Tauri 2 (Rust), tauri-specta (type-safe IPC), tauri-plugin-frame, tauri-plugin-os, tauri-plugin-log |
| Tooling   | Bun (package manager), ESLint, Prettier, React Compiler              |

## Features

- **Frameless window, no flash on startup** — the window is created with
  `visible: false` and shown from the frontend only after React has mounted,
  avoiding the transparent-frame flash on Windows.
- **Custom cross-platform TitleBar**
  - Windows / Linux: self-drawn caption buttons (minimize / maximize / close)
    with a Windows 11 Fluent look; the titlebar is a drag region.
  - macOS: native traffic lights; the custom buttons are hidden and the
    title spacing collapses in fullscreen (traffic lights move to the system
    toolbar).
- **Windows 11 integration**
  - Snap-layout flyout over the maximize button, provided by
    `tauri-plugin-frame` (the `titlebar_height` / `button_width` values must
    match the CSS in `TitleBar.tsx`).
  - Rounded corners via `DwmSetWindowAttribute` (`DWMWCP_ROUND`), applied in
    `src-tauri/src/lib.rs`.
- **Theme system** — `light` / `dark` / `system`, toggled from the titlebar,
  persisted to `config.json`.
- **Window state persistence** — window position, size, and maximized state
  are saved to `window.json` on close and restored on startup (falls back to
  centering when nothing is saved or the state is invalid).
- **Type-safe IPC** — commands are defined in Rust with `tauri-specta`; the
  frontend bindings (`src/bindings.ts`) are auto-exported in debug builds.

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (the project is locked with `bun.lock`)
- Rust (stable; the crate requires `rust-version` ≥ 1.77.2)
- Platform WebView: WebView2 (Windows, built into Win 11), WKWebView (macOS),
  or WebKitGTK (Linux)

### Install & run

```bash
bun install            # install frontend dependencies
bun run tauri dev      # start the Vite dev server + Tauri app
```

### Build a release bundle

```bash
bun run tauri build
```


## Data Files

Runtime data is stored as plain JSON next to the app, resolved per platform:

| Platform       | Path                                                        |
| -------------- | ----------------------------------------------------------- |
| macOS          | `~/Library/Application Support/<bundle-id>/`                |
| Windows/Linux  | directory of the running executable                         |

- `config.json` — theme setting (`"light"` / `"dark"` / `"system"`).
- `window.json` — last window geometry (`width`, `height`, `x`, `y`, `maximized`).

## Platform Notes

- `src-tauri/src/lib.rs` wires up the window state restore on startup and the
  save-on-close handler; the `"main"` window label must match
  `tauri.conf.json`.
- On Windows, `tauri-plugin-frame`'s `titlebar_height` (32) and `button_width`
  (46) are matched against the CSS in `TitleBar.tsx` — keep them in sync or the
  snap-layout overlay will drift off the maximize button.
- Add Rust commands with `#[tauri::command]` + `#[specta::specta]` and register
  them in `collect_commands!` in `src-tauri/src/lib.rs`; in debug builds the
  TypeScript types are regenerated into `src/bindings.ts` automatically.

## Adding shadcn/ui components

```bash
npx shadcn@latest add button
```

This places the ui components in `src/components/ui`.
